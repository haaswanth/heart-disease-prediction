# ❤️ Heart Disease Prediction

A machine learning project that predicts whether a person is likely to have heart disease based on medical input features.

## 🚀 Live Demo
(https://heart-disease-prediction-rhryqvaywwdscnv86unqk7.streamlit.app/)

## 📌 Project Overview

This project uses machine learning classification algorithms to predict heart disease.

The project includes:

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature scaling
* Machine learning model training
* Model evaluation
* Model comparison
* Model deployment using Streamlit

## 🤖 Machine Learning

Several classification algorithms were evaluated during the project.

The final model used for deployment is **K-Nearest Neighbors (KNN)**.

The trained model and preprocessing objects are saved using `.pkl` files.

## 📊 Model

**K-Nearest Neighbors (KNN)** was selected as the final model for deployment based on the evaluation performed during the project.

The model uses scaled input features before making predictions.

## 🔮 Prediction

The application accepts the required patient-related inputs and predicts whether the person is likely to have heart disease.

> **Note:** This project is for educational and demonstration purposes only. It should not be used as a substitute for professional medical advice.
